말풍선 편집기

패널 미리보기 폭 확대

실제 독자용 말풍선 엔진(js/bubbles.js)·휴대폰 UI·확대 인셋이 그대로 그려진 화면 위에서 편집합니다(원화·대사 불변). 말풍선이나 노란 ■(꼬리 시작)·파란 ●(꼬리 끝)·초록 ■(크기)를 끌거나, 선택 후 화살표 키(Shift=크게)로 움직입니다. 주황 테두리 = 정밀값 적용됨, 빨간 테두리 = 여러 말풍선으로 나뉜 대사(정밀값 미지원).

말풍선 선택

위치·배치

크기·모양

모서리 60 = 타원형(원래 모양). 글자·여백·모서리는 실제 화면 px, 가로·세로는 조각 대비 %입니다. 가독성 기준(말 16px 등)은 편집기가 막지 않으니 확인하세요.

꼬리

방향 0°=오른쪽, 90°=아래. 방향·길이는 시작점에서 끝점까지입니다. 곡선 0 = 직선.

초기화

저장·내보내기

자동 저장: 이 브라우저(localStorage). 패치의 manual 은 독자용 엔진(js/bubbles.js)이 읽는 정밀값입니다(없으면 기존 모습 그대로). 직접 커밋·본편 적용은 하지 않습니다.

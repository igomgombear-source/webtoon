패널 미리보기 폭 확대

원화 위에 말풍선을 올려 편집합니다(원화·대사는 바뀌지 않음). 말풍선이나 노란 ■(꼬리 시작)·파란 ●(꼬리 끝)·초록 ■(크기)를 끌거나, 선택 후 화살표 키(Shift=크게)로 움직입니다. 휴대폰 화면 UI 는 표시되지 않습니다.

말풍선 선택

위치·배치

크기·모양

모서리 60 = 타원형. 크기 값은 360px 기준이며 미리보기 폭에 비례해 커집니다. 글자 16px 미만 등 가독성 기준은 편집기가 막지 않으니 확인하세요.

꼬리

방향 0°=오른쪽, 90°=아래. 방향·길이는 시작점에서 끝점까지입니다. 곡선 0 = 직선.

초기화

저장·내보내기

자동 저장: 이 브라우저(localStorage). 패치의 manual 은 편집기 정밀값이며 현재 독자용 엔진(js/bubbles.js)은 아직 읽지 않습니다(pref·tail 만 호환). 직접 커밋 기능은 없습니다.

## 원본과 수정 범위

- 59 원본은 GitHub ep01-redesign-v3의 지정 경로에서 읽기 전용으로 확보했다. 로컬 이전 원본과 SHA-256이 같았다.
- 94-a·b는 사용자가 지정한 원본을 사용했다. 원본 파일은 덮어쓰지 않았다.
- 기존 2D 화풍을 기준으로 이미지 편집 도구에서 손 자세를 수정한 후, 수정 손과 필요한 복원 영역만 원본에 합성했다. 화면·휴대폰 전체의 생성 결과를 그대로 사용하지 않았다.

- 94의 기존 손을 지운 화면 내부는 원본에서 채취한 중성 회색으로 정리했다. 회색 합성 면과 화면 크기를 유지했으나 기존 미세한 회색 질감까지 픽셀 단위로 동일하지는 않다. 손 제거로 드러난 하단 프레임·작은 배경 영역도 복원했다.

## 합성 순서 및 주의사항

1. 원화 → 회색 면 안에 클립한 HTML/CSS 또는 SVG UI → 손가락 전경 PNG 순서로 겹친다. 전경은 원화와 같은 캔버스 크기이므로 같은 위치·비율로 올린다.
2. UI-occlusion-mask.png는 흰색=손가락 가림, 검정=노출. UI-foreground.png는 해당 손가락 픽셀을 담은 투명 PNG다. 둘 다 1080px 원화 좌표계이며 웹 화면 너비가 W이면 모든 좌표에 W/1080을 곱한다.
3. 59 통화 버튼 중심 권장 위치는 (535,400) 부근. 엄지 끝이 그 위에 겹쳐 있지만 통화 연결·진행 표시나 터치 파동을 넣지 않는다.
4. 94-a 받기 슬라이더 시작 중심은 (445,810) 부근. 94-b는 같은 슬라이더에서 손잡이가 (635,810) 부근으로 이동한 중간 동작으로 맞춘다. 손의 높이 차이와 원근 때문에 손끝 좌표가 완전히 수평으로 같지는 않다.
5. 손가락 그림자를 UI 위에도 유지하려면 전경 마스크를 약하게 블러하여 별도 그림자 레이어를 만든다. a는 이격 그림자, b는 짧은 접촉 그림자를 사용한다. 원화 속 회색 위 그림자는 UI로 가려질 수 있다.
6. 위 버튼 좌표는 수정 원화에 맞춘 합성 기준점이다. 기존 HTML/CSS 버튼 위치는 이번 작업에서 열거나 변경하지 않았으므로, 기존 UI와 무수정 호환됨을 보증하지 않는다. 실제 UI를 올린 후 손가락·버튼 정렬과 360px 가독성을 확인해야 한다.

조사 결과(이전): 상태 표시줄이 점 3개짜리 단순 표시였고 Dynamic Island 가 없었다. 말풍선 색(받은 문자 #2a2e38 / 보낸 문자 #3b6fd4), 입력창·알림 카드 색이 파일 곳곳에 하드코딩. 85·86·90·104 메시지에 흐림(blur) 4건, 85·104 강조 문장 밖 글자는 흐림+투명도 55%. 49컷 프레임은 70컷판과 같은 범용 검은 틀(해인 폰인데 Lavender 아님). 기기 외관(베젤·모서리)은 원화마다 다르며 원화라 코드로 바꿀 수 없음.

## 2. 통일한 디자인 (iPhone 17 일반형 기준) — `css/phone-system.css`
- **토큰**: 글꼴 Pretendard(시스템 산세리프 대체), 파랑 #0a84ff · 초록 #30d158 · 빨강 #ff453a. 승민 = Black → 어두운 화면(배경 #000, 받은 문자 #262629, 보조 글자 #8e8e93). 해인 = Lavender → 밝은 화면(배경 #f2f2f7, 받은 문자 #e9e9eb). 보낸 문자는 둘 다 파랑.
- **상태 표시줄**: 시각 · 가운데 **Dynamic Island**(가로 30%) · 신호 4칸·와이파이·배터리. 가상 화면(가로 300px) 기준 px 고정이라 모든 컷에서 같은 비율로 보인다(`js/screenui.js` `status()` 하나로 생성).
- **메시지 UI**: iOS 메시지형 머리(‹ · 가운데 원형 아바타 · 이름), 말풍선 모서리 1.15em·꼬리 쪽 0.32em, 시각은 말풍선 아래 회색. 입력창·전송 버튼·알림 카드·연락처 버튼·수신 슬라이더가 같은 토큰을 쓴다. 확대 인셋·83 읽기 카드도 같은 색.
- **49컷**: `phone-v3` 클래스(104컷판만) — iPhone 비율의 둥근 모서리, 얇은 검은 베젤, **Lavender 프레임**과 측면 버튼.
- 컷마다 다른 것은 데이터만: 시각·내용·글자 크기(fs)·화면 좌표. 기존 원화 위 matrix3d 합성 방식 유지.

## 3. 모자이크·흐림 제거
- `blur: true` 4건 삭제: 85(보낸 문자 “해인쌤, 몸은 좀 괜찮으세요? 휴대폰은 효은쌤께 드렸어요.”), 86·90(받은 문자 “승민쌤, 저 해인이에요. …”), 104(보낸 문자 “푹 쉬세요. 학교 일은 걱정하지 마세요.”). 모두 대본에 있는 문장이라 그대로 보인다(문장·시각·발신자·순서 변경 없음 — 데이터 diff 는 blur 줄 삭제뿐).
- 85·104 강조 문장 밖 흐림(`su-dim`) 제거, 강조(85 “휴대폰 잘 받았어요.” · 104 “걱정해 주셔서 감사해요.”)는 하이라이트로 유지 → 미스터리 연출 보존.
- 92·94 수신 번호 `031-7○○-○○○○` 의 ○ 는 대본 표기라 그대로 둠(인위 모자이크 아님).
- 원화 속 손가락이 화면을 가리는 부분(86 입력창, 104 마지막 보낸 문자 일부)은 원화의 앞 손가락이라 그대로.

## 말풍선 v4 — 104컷 전체 적용 (렌더러 승인, 컷별 배치는 미승인)
사용자가 승인한 것은 **렌더러(디자인·기본 배치 규칙)**이며, 104컷 각각의 말풍선 위치는 아직 승인 전이다. 50컷 독백 배치만 승인됐다.
- 보는 곳: 독자 화면 `index.html#ep01v3` (기본으로 v4 적용). 제작용 표시까지 보려면 `index.html?review=1#ep01v3` (보호 영역은 `&zones=1`). 예전 렌더러는 `?bubbles=off`.
- 파일: `js/bubbles.js`(엔진), `css/bubbles.css`(모양·`@font-face`), `data/ep01v3-bubbles.js`(컷별 예외·실측 보호 영역). 대사 데이터에 설정이 없는 컷은 `at·panel·style·who`와 컷 비율에서 임시 설정을 자동 생성한다.
- 규칙: 유형별 모양(말=흰 둥근 타원+꼬리, 독백=테두리 없는 반투명 사각·세리프, 전화=톱니+폰 쪽 꼬리, 화면 밖=테두리 밖 꼬리, 자막=각진 캡션), 글자 크기 고정(말 16·독백 15·자막 13.5px 이상), 한글 단어 단위·문장 끝 우선 줄바꿈, 줄 폭에 맞춘 말풍선 크기, 보호 영역(얼굴·눈·손·핵심 소품) 비침범, 같은 화자 연속 대사는 목으로 이어 붙임, 읽는 순서 유지, 꼬리가 다른 말풍선·보호 영역을 지나지 않고 화면 밖으로 나가지 않음.
- **경계·사이·틀 밖 배치를 적극 사용**(사용자 지시): 콘티가 정한 경계-상·경계-하(`edge-*`)는 컷 안쪽보다 먼저 쓰고, 말풍선 몸체와 꼬리가 컷 경계를 넘는 것을 허용한다. 경계에 걸친 만큼 앞뒤 여백을 흐름에 만들어 이웃 컷을 가리지 않는다. 텍스트는 항상 말풍선 안에 완전히 들어가야 한다.
- 33컷은 예외로 제작기준 v2의 '각 조각 안쪽'을 우선한다(`bandBase`로 여백 띠는 마지막 수단). 5개 중 3개가 조각 안, 2개(오른쪽 조각)는 자리가 없어 그 조각 바로 아래 여백에 놓고 꼬리를 조각 안으로 넣었다. 이 배치는 최종 승인이 아니며, 원화가 오면 원화와 말풍선 공간을 함께 조정한다.
- 50컷: 현재 독백 배치 승인. 화면 아래의 '부장'은 말풍선 화자 이름표였다(`showSpeakerNames: true` 때문). 정본 9-6에 맞춰 `false`로 바꿨고 화자 이름은 스크린리더용(`sr-only`)으로만 남는다.
- 83컷: 문자 UI만 승인. 현재는 원화 합성 전 임시 문자 화면이며 최종은 두 손으로 쥔 휴대폰에 표시한다. 단독 휴대폰 화면은 49컷만(자동 QA가 `.cut-phone`이 [49]뿐인지 검사). 63컷은 휴대폰 UI 미리보기(원화 합성 전).
- 보호 영역: 원화가 없는 컷은 컷 모양으로 가정한 임시값(`approved:false`, 최종 승인 상태 아님). 승인 원화에서 직접 잰 값은 35·50컷뿐. 원화가 오면 `data/ep01v3-bubbles.js`의 `cuts`에 실측값을 넣는다.
- **제작용 표시 분리**: DRAFT 배지, 컷 번호, '그림 준비 중', 틀 밖 표시, 조립 메모, 보호 영역, 문자 화면 '원화 합성 전' 표기는 `?review=1`에서만 나온다(독자 화면에는 DOM에도 없음). 그림이 없는 컷은 분위기 색 면만 보인다. 자동 QA가 독자 화면에 해당 요소·문구가 없는지, 검수 모드에는 있는지 둘 다 검사한다.
- 글꼴(직접 호스팅, OFL): `assets/fonts/` Pretendard Medium·SemiBold(공식 배포 부분집합 woff2), Noto Serif KR Medium(설치된 Noto Serif CJK KR Medium에서 KS X 1001 한글+사용 글자만 남긴 woff 부분집합. 같은 서체이며 라이선스 파일 포함). `font-display: swap`, Pretendard는 preload. 엔진은 세 글꼴을 실제로 불러온 뒤 줄바꿈을 재고, 자동 QA가 세 글꼴이 `loaded`인지 확인한다.
- 알려진 한계: 말풍선 위치는 컷별 승인 전 / 보호 영역은 대부분 가정값 / 실제 기기 테스트 미실시 / Noto Serif KR은 woff(약 526KB, woff2 변환 도구 없음) / 글꼴 전체 약 1.06MB.

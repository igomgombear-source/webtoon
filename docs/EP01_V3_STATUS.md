## 휴대폰 화면 (컷 49 / 63)
- 배경 사진과 시계·날짜·알림을 분리. 시계·알림은 CSS(`cqw` 단위)로 그리고 시각은 데이터(`phone.time`)로 지정 → 다른 시각에 재사용 가능.
- 49컷 09:17 (해인), 63컷 10:36 (승민 화면).
- 배경은 승인본에서 구워진 시계를 지운 파생본(`assets/phone/*-CLEAN-DERIVED.webp`). **파생본은 승인 대기.** 원본(`*-DRAFT.webp`)은 그대로 보존.

## 렌더러 (제작기준 v2)

## 미완성 / 미확정
- 50컷 말풍선 위치(개선안: 독백 1은 좌상 한 줄, 독백 2는 우하 경계-하): 사용자 승인 전. 승민의 눈·얼굴·휴대폰·손가락은 가리지 않음. 개선 전에는 우상단 2개가 이마·눈 가까이 쌓여 있었음.
- 1·16·76 원화는 새 화풍(35/50/66)과 그림체가 다를 수 있음. 화풍 통일은 사용자 승인 없이 하지 않음.
- 33컷: 조각 안쪽 배치 유지(말풍선 6개 모두 각 조각 안, 320·360px). 우하 조각의 두 번째 말풍선까지 안쪽으로 되돌림.
- 62컷: 전화 음성은 우상(폰 쪽), 첫 독백은 안-좌하, **둘째 독백(‘토요일이라 아무도 없겠지.’)만 띠 아래**. 3:1 띠 높이가 낮아(360px에서 120px) 말풍선 3개를 읽을 수 있는 글자 크기로 모두 넣을 수 없음.
- 74컷: 화자 없는 침묵(`style:'silence'`, 말줄임표만, 말풍선·이름 없음). 대사 추가 없음.
- 25컷 메모: 옛 번호(27·28) → 24·25 로 수정.
- 해인 CLEAN-DERIVED 배경: 시계를 지운 자리에 잎이 뭉개진 흔적이 있음(시계 글자에 가려 보이지만 시계를 숨기면 드러남). 승인 전.
- 얼굴 위 말풍선 겹침은 자동 점검 불가 → 눈으로 확인(1·16·35·50·66·76 만 가능, 나머지는 임시 컷).
- 컷 35: 말풍선 아래 가장자리가 해인의 머리 윗부분에 닿음(얼굴은 가리지 않음).
- 실제 기기 테스트 미실시 (headless Chrome 만 사용).

## 5. 승민 `sit-hold-phone-likeness.webp` 오른쪽 붉은·보라색 얼룩

- **원인: 완전히 투명한 픽셀(알파 0)에 저장된 RGB 값.** 오른쪽 영역 투명 픽셀 337,104개 중 168,351개가 붉은·보라색 RGB 를 갖고 있었다.
- 흰색·검은색 배경 합성에서는 보이지 않음 → **뷰어·브라우저 화면에는 나타나지 않는다.** 투명도를 무시하는 미리보기(썸네일 등)에서만 얼룩으로 보인다.
- 무손실 WebP 가 투명 픽셀의 원래 색을 그대로 보존해서 생긴 것. 손실 WebP 로 다시 저장한 뒤 168,351개 → 120개(가장자리 근처의 어두운 값)로 사라졌다. 알파(투명도)는 전과 픽셀 단위로 같다.

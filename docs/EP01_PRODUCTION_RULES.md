## 1. 원화
- **화풍**: 기존 Work 원화의 **2D 펜선 + 셀 채색**. 반실사형 한국 미스터리 웹툰, 인체 비례·공간은 사실적. 사진·3D 렌더 느낌, 애니풍 굵은 외곽선 금지.
- **기준 원화**: **35컷(해인)·50컷(승민)·66컷(효은)** 등 기존 승인 이미지. 1·16·76컷은 승인 시안이나 그림체가 다를 수 있다. 화풍 통일은 사용자 승인 없이 하지 않는다.
- **대체 금지**: 원화를 SVG·CSS 도형·아이콘으로 대체하지 않는다.
- **글자 레이어**: 대사·말풍선은 원화에 넣지 않고 별도 레이어(`data/ep01v3-bubbles.js`, `js/bubbles.js`). 그림 속 한글·숫자(시각·문자 내용 등)도 원화에 생성하지 않고 웹 레이어로 얹는다.
- **일관성**: 승인 캐릭터의 얼굴·체형·의상 유지(§1-1). 얼굴 하나를 좌우 반전·크롭만 바꿔 다른 감정에 쓰지 않는다.
- **교체**: 승인 안 된 원화로 교체 금지. 새 원화는 **새 파일 이름**, 기존 원화 덮어쓰기·수정 금지. 승인 전 그림은 `-DRAFT`를 붙이고 완성으로 보고하지 않는다.
- **연결**: `python3 tools/lqip.py assets/cuts/ep01v3/<파일>` 출력을 `imageLqip`에 넣는다. 앱에서 원화에 필터·오버레이·투명도 금지.
- **비교 검수**: 원화 제작 후 모바일 화면에서 **기준 원화(35·50·66)와 나란히** 선·채색·밝기·얼굴을 비교한다. 자동 QA 통과만으로 승인하지 않는다.
- **비공개 자료**: `참고_비공개` 이미지(승민 설정표, 해인 외형 참고), 교무실 자리 사진, 바탕화면 원본은 저장소·이슈·PR·공개 채널에 올리지 않는다.

## 2. 연출
- 말풍선 꼬리는 **발화자**를 향한다. 화면 밖 발화·전화 음성은 정해진 형식을 따른다.
- 얼굴(눈·입)과 중요한 행동(손, 휴대폰, 핵심 소품)을 말풍선으로 가리지 않는다. 경계-상, 경계-하, 컷 사이, 틀 밖 자리를 적극 쓰되 글자는 말풍선 안에 완전히 들어가야 한다.
- 글자 크기: 말 16px, 독백 15px, 자막 13.5px 이상. 어떤 폭에서도 13px 미만 글자 금지.
- 콘티의 **대사·시각·날짜·컷 순서·스토리·반전 구조**를 보존한다. 사용자가 요청·승인한 변경만 예외이며 무엇이 바뀌었는지 보고한다.
- 1화 고정: 해인의 09:50 업무메일 본문은 공개하지 않는다. 10/31 오전 강당에 해인은 등장하지 않는다. 문상윤은 목소리만 나온다. 마지막 컷에서 범인과 반전을 노출하지 않는다. 17번 보관함, 파란 파일 17, C-17 출입카드는 서로 다른 물체다.
- 표정: 웃음은 11~12, 18~19, 47컷만 허용. 85컷은 아주 작은 안도. 효은에게 수상한 연출 장치(안경 반사로 눈 가리기 등) 금지.
- 콘티에 있는 **글자형 효과음**은 유지·복원 가능, 콘티에 없는 효과음은 새로 만들지 않는다. **오디오 재생 기능은 추가하지 않는다.**

## 3. 휴대폰
- **iPhone 17 일반형**. 승민 **Black**, 해인 **Lavender**, 두 폰은 다른 물건으로 구분한다.
- **공통 디자인 시스템**(현재 `ep01-phone-ui-refactor`의 `css/phone-system.css`, `js/screenui.js`의 `status()`). 승민은 어두운 화면, 해인은 밝은 화면. 상태 표시줄에 Dynamic Island, 메시지 화면은 iOS 메시지형. 컷마다 다른 것은 데이터(시각, 내용, 좌표)뿐.
- 메시지에 **모자이크·흐림 금지**. 강조 문장도 **노란 형광펜·굵기 없이** 다른 문장과 같은 글자로 둔다(휴대폰 UI 확정 사항, `docs/EP01_PHONE_UI_SYSTEM.md`). 원화 속 손가락이 화면을 가리는 것은 허용.
- 메시지 원문 **창작 금지**: 대본에 없는 문장·시각·발신자를 만들지 않는다. 대본의 `○` 표기(예: `031-7○○-○○○○`)는 그대로. 화면 내용이 대본에 없으면 화면을 비워 둔다.
- 휴대폰 UI는 SVG·CSS 사용 가능(화면 UI 한정). 기기 외관은 원화로 그린다.
- 원화가 바뀌면 그 컷의 화면 좌표(`quad`·`clip`·`aspect`)를 다시 잰다.

## 4. 개발 및 검수
### 4-1. 범위와 브랜치
- 수정 대상은 **104컷판**(`#ep01v3`, `data/ep01v3*.js`). 70컷 구판은 2026-11-22 사용자 지시로 제거했다(`#ep01` 주소는 `#ep01v3`로 연결). 104컷판이 유일한 정식 EP01.

## 3. 교체 방법

### 3-1. 중앙 관리 (이번에 추가)

컷 데이터(`data/ep01.js`)는 이제 인물 파일 경로를 직접 쓰지 않고 `@인물/이름` 으로 부른다. 실제 경로는 **`data/characters.js` 한 곳**에만 있다.

```js
'haein/sit-talk': { src: 'assets/characters/haein/sit-talk.webp', size: { w: 1656, h: 1220 }, status: 'temporary', … },
```

공식 그림을 받으면:

1. 새 파일을 같은 폴더에 **새 이름**으로 넣는다 (예: `assets/characters/haein/sit-talk-official.png`). 기존 임시 파일은 비교·되돌리기를 위해 남겨 둔다.
2. `data/characters.js` 에서 그 항목의 `src`, `size` 를 바꾸고 `status: 'official'` 로 바꾼다. 파일 형식과 확장자를 일치시킨다 (PNG → `.png`, WebP → `.webp`, 알파 유지).
3. 이 한 줄로 그 이름을 쓰는 **모든 컷**이 함께 바뀐다 (예: `sit-talk` → 07·18·26·28).
4. 검수: `tools/review.html?w=375` 제목이 `missing=none` 인지, 각 컷의 얼굴 위치·말풍선 겹침을 확인한다.

### 3-2. 좌표를 다시 맞춰야 하는 경우

컷 좌표 `x·y·w` 는 캔버스 가로 폭 기준 %이고, 높이는 그림 원본 비율로 정해진다. 따라서

- **같은 크기 + 같은 구도**(머리 위치·투명 여백·몸 비율이 같음)로 받으면 → 좌표 수정 없이 끝 (A안 그대로).
- 크기·여백·구도가 다르면 → 그 이름을 쓰는 컷의 `x·y·w` 만 다시 맞춘다. 컷의 대사·시간·비율·순서는 건드리지 않는다.
  공식 그림을 요청할 때 **현재 파일과 같은 캔버스 크기, 같은 머리 위치**로 만들어 달라고 하면 좌표 수정이 필요 없다.

### 3-3. 컷별 주의

- **26 (클로즈업)**: `w: 174.8` 로 원본을 크게 확대해 쓴다. 공식 그림 해상도가 1656px 폭보다 낮으면 흐려진다 → 같은 폭 이상으로 받는다.
- **15·20 (폰이 그림에 포함)**: 해인 폰 디자인(회보라색 무광 케이스, 좌상단 대각선 듀얼 렌즈)을 공식 그림에서도 유지해야 09·13·27·28 의 폰과 맞는다.
- **22 (뒷모습)**: 얼굴이 없으므로 머리 색·길이·의상만 맞으면 된다. 공식 외형의 머리 길이가 크게 다르면 교체.
- **08·13 (손만 보임)**: 공식 의상이 아이보리 니트가 아니면 교체. 의상이 같으면 그대로 둬도 된다.
- **27 (key 완성 컷)**: 한 장짜리 원화라 해인 소매만 바꿀 수 없다. 의상이 바뀌면 컷 전체를 다시 그린다 (61컷과 같은 폰, 역방향 구도 유지).
- **07·28 (투샷)**: 승민 레이어와 크기 비율이 맞는지 확인한다 (같은 축척 원칙).

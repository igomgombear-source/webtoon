# 1화 그림 넣는 곳

1. 이 폴더에 그림 파일을 넣는다. 예: `01.jpg`, `02.jpg` … `70.jpg`
2. `data/ep01.js` 에서 해당 컷의 `image: null` 을 `image: '01.jpg'` 처럼 바꾼다.
3. 그림이 들어가면 임시 컷 대신 그림이 보이고, 영역 비율은 그림 자체 비율을 따른다.

- 권장: 가로 1600px로 작업해 웹용으로 내보낼 때 720~800px 폭 JPG/WebP로 줄인다.
- 그림에는 글자(말풍선·문자 내용)를 넣지 않는다. 대사와 휴대폰 화면 글자는 데이터에서 텍스트로 표시된다.
- 파일이 없거나 이름이 틀리면 그 컷은 임시 컷으로 남는다(페이지는 멈추지 않는다).

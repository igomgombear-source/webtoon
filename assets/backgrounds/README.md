# 배경

장소별 폴더 하나, 카메라 각도·시간대별 파일 하나.

```
backgrounds/<장소>/<시간대>-<각도>.webp
예) backgrounds/musicroom/night-wide.webp
    backgrounds/auditorium/day-front.webp
```

- 조립 컷 캔버스와 같은 비율로 만들면 잘리지 않습니다. 비율이 다르면 가운데 기준으로 잘려 캔버스를 채웁니다.
- 장소 이름 예: `musicroom`, `auditorium`, `schoolgate`, `hall-corridor`, `backstage`, `stairs`, `home`

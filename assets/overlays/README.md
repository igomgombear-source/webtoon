# 조명 보정 레이어

조립 컷(compose) 맨 위에 얹는 반투명 SVG. 배경과 인물의 빛을 장면별로 통일한다 (제작 마스터 §2 "조명은 배경별 LUT/오버레이로 통일").

- 캔버스 전체를 덮도록 `{ x: 0, y: 0, w: 100, h: <세로/가로×100> }` 로 넣는다. 1:1 이면 `h: 100`, 4:5 이면 `h: 125`.
- 얼굴·의상 색을 바꾸지 않을 정도로 약하게 유지한다 (전체 10% 안팎 + 가장자리 어둠).

| 파일 | 장면 |
|---|---|
| `musicroom-night-grade.svg` | 10/30 밤 음악실 (06~28) |
